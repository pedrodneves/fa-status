# FA Status Portal

A public page where Featured App applicants check the status of their own FA applications and DVP requests, without seeing anyone else's. Applicants enter the email address they applied with and receive a private link to their applications. The page also has a public board, for everyone, of every application and its status, with only the app's name, type, Party IDs and, once approved, its announcement (also as JSON and CSV).

The data comes from the Featured App Submissions and Asset Moving Status Requests boards on Monday, read-only.

- `docs/`: the page (GitHub Pages)
- `apps-script/`: the Google Apps Script backend
